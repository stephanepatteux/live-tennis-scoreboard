How scoring works

This is a live singles tennis scoreboard. Press a player's Point button to award them a point; the board updates instantly and stays live.

Points within a game

  • Points count up 0 → 15 → 30 → 40 → game.
  • At 40–40 the game is at deuce. A player must then lead by two points: winning one point shows Ad (advantage), and winning the next takes the game.

Games and sets

  • The first player to 6 games with a two-game lead wins the set.
  • At 6–6 a tiebreak is played: first to 7 points, win by two.
  • The match is won by the first player to win the configured number of sets (best of 3 by default).

API

  • GET /api/score — current match snapshot (JSON).
  • POST /api/point — body {"player": 0|1} awards a point.
  • POST /api/reset — start a fresh match.
  • GET /api/health — liveness probe.
